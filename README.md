# home-exchange-uniapp

房屋互换项目 —— 客户端小程序/多端应用，基于 [uni-app](https://uniapp.dcloud.net.cn/) + Vue3 开发。

## 项目简介

本仓库是「房屋互换」项目的客户端（Client）代码，面向微信小程序 / H5 / App 等多端运行。

## 技术栈

- uni-app
- Vue3（`<script setup>` 组合式 API）
- TypeScript
- Pinia（状态管理）

## 相关仓库

- 后端服务：`home-exchange-server`
- 后台管理前端：`home-exchange-admin`
- 变更与规格管理：`openspec/`
- 产品文档与设计资料：`product/`

## 开发约定

本项目所有新功能、业务规则变更及 API 契约变更统一通过 [OpenSpec](https://github.com/Fission-AI/OpenSpec) Change 管理，详见仓库根目录 `.cursor/rules/front.md`。
